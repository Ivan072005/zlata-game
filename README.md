# Что бы ты выбрала? 💗

Игра на двоих для Вани и Златы. Каждый вставляет свой список вопросов, всё попадает в общий пул, и вы тянете вопросы по очереди.

Формат: один вопрос в строке. `Море / Горы` — выбор из двух, строка без `/` — открытый вопрос, на который каждый пишет ответ.

## Запуск у себя

```bash
git clone https://github.com/Ivan072005/zlata-game.git
cd zlata-game
npm install
npm run dev
```

Открой http://localhost:8888. Для второго игрока открой ту же ссылку в режиме инкогнито или с телефона в той же Wi-Fi (адрес покажется в терминале).
