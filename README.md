# Что бы ты выбрала? 💗

«Правда или действие» на двоих для Вани и Златы. Каждый добавляет свои вопросы и действия в общий пул, вы по очереди выбираете «Правда» или «Действие».

- **Правда**: вопрос, отвечаете оба. `Море / Горы` — выбор из двух, строка без `/` — открытый вопрос.
- **Действие**: выполняет тот, кто тянул; задание берётся из тех, что написал партнёр. Партнёр засчитывает или нет, можно и «слиться».

## Запуск у себя

```bash
git clone https://github.com/Ivan072005/zlata-game.git
cd zlata-game
npm install
npm run dev
```

Открой http://localhost:8888. Для второго игрока открой ту же ссылку в режиме инкогнито или с телефона в той же Wi-Fi (адрес покажется в терминале).

## Код входа

Игра открывается только по коду (по умолчанию `812`). Поменять его можно без правки кода: в Netlify → Project configuration → Environment variables добавь `ROOM_CODE` и сделай новый деплой. После смены кода оба телефона попросят ввести его заново.

## Установка на телефон

- Android (Chrome): кнопка «📱 Установить на телефон» внизу игры или меню браузера → «Добавить на главный экран».
- iPhone (Safari): «Поделиться» → «На экран „Домой“».
